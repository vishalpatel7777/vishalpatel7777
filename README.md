---

### How I think about building

I care about what happens below the abstraction — not just that something works, but why it works and what breaks it under load or under attack.

My work spans authentication flows (JWT, HTTP-only cookies, API keys), security hardening (rate limiting, XSS protection, CORS), API design with proper validation and documentation, and wiring up deployment pipelines that don't require manual intervention. The frontend is a delivery layer. The interesting problems live in the systems behind it.

Currently, the problems that pull my attention most are distributed architecture, event-driven design, and how to build systems that stay maintainable as they grow.

---

### Engineering things I actually care about

- Security is a first-class concern, not an afterthought
- APIs should be self-documenting and predictable
- Performance work should be measurable — Lighthouse scores, not gut feelings
- Folder structure and separation of concerns are not cosmetic choices
- Error handling and logging are part of the feature, not cleanup work
